# Site Mistral Home

Le site vitrine de Mistral Home (ménage, grands ménages et débarras à L'Isle-sur-la-Sorgue).
C'est un site simple : du HTML et du CSS, sans outil à installer. Il est publié gratuitement avec GitHub Pages : https://fbastide67.github.io/mistral-home/

## Contenu du dossier

| Fichier | Rôle |
| --- | --- |
| `index.html` | La page d'accueil (tous les textes du site sont ici) |
| `mentions-legales.html` | Mentions légales, **à compléter** (passages surlignés en jaune) |
| `css/style.css` | Couleurs, polices et mise en page |
| `img/` | Logo, pictos, favicon, image de partage pour les réseaux sociaux |
| `fonts/` | Polices Josefin Sans et Josefin Slab (celles de la plaquette) |

## Modifier un texte

1. Sur GitHub, ouvrez `index.html`.
2. Cliquez sur l'icône crayon (« Edit this file »).
3. Changez le texte entre les balises, sans toucher aux `<` `>`.
4. Cliquez sur « Commit changes ». Le site est mis à jour en 1 à 2 minutes.

## Publier avec GitHub Pages

1. Dans le dépôt : **Settings → Pages**.
2. « Source » : *Deploy from a branch*, branche `main`, dossier `/ (root)`, puis **Save**.
3. Après 1 à 2 minutes, l'adresse du site s'affiche en haut de cette page.

## Avant la mise en ligne

- [ ] Compléter `mentions-legales.html` (SIRET, adresse, nom)
- [ ] Vérifier la liste des communes dans la section Contact
